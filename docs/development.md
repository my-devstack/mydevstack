# Development

From-source workflow for the Go proxy, the Vue 3 UI, and the Playwright E2E suite.

## Prerequisites

| Tool | Version | Notes |
|---|---|---|
| Go | `1.26` | `go version` to check. |
| Node.js | `24` | `node -v`. `nvm install 24 && nvm use 24` if needed. |
| pnpm | latest | `npm i -g pnpm`. |
| Docker | 24+ | Only required for E2E (emulator container) or the Compose quickstart. |
| Emulator | LocalStack / FloCi / MiniStack | Required for E2E on port `4566`. |

## Run locally

### With Make (recommended)

```bash
# Terminal 1 — Go proxy on :8081 (auto-runs `go mod tidy`)
make run-proxy

# Terminal 2 — Vue dev server on :3000 (Vite proxies API paths to :8081)
make run-ui
```

Open `http://localhost:3000`. The dev UI talks to the Go proxy through the Vite dev proxy — no CORS, no manual backend URL.

### Without Make

```bash
# Go proxy
cd pkg/proxy && go run cmd/server/main.go

# UI (separate shell)
cd pkg/ui && pnpm install && pnpm run dev
```

### Production build

```bash
make build       # Go multi-platform binaries + Vue dist
make dist        # Vue dist only
```

## Test suite map

| Suite | Command | Needs emulator? | Notes |
|---|---|---|---|
| Go unit + integration | `make test` or `make unit` | No | Excludes `mocks/`. `make unit` runs `go mod tidy` first. |
| Go unit + coverage HTML | `make unit-coverage` | No | Output: `unit.html`. |
| Vue unit + integration | `pnpm run test:run` from `pkg/ui` | No | Vitest. Single file: `pnpm exec vitest run src/api/services/s3.test.ts`. |
| E2E (Playwright) | `make test-e2e` | **Yes** (`:4566`) | Needs proxy on `:8081` + UI on `:3000` + emulator on `:4566`. |
| E2E single spec | `cd pkg/test && pnpm exec playwright test e2e/services/s3.spec.ts` | Yes | |
| E2E single test | `cd pkg/test && pnpm exec playwright test e2e/services/s3.spec.ts -g "create bucket"` | Yes | |

E2E tests live in `pkg/test`, **not** `pkg/ui/e2e`. They import from `./fixtures.js` (not `@playwright/test`) and use hash routing (`/#/services/<service>`). `PROXY_URL` overrides the default `http://localhost:8081`.

## Lint and format

```bash
make lint            # All (Go + Vue)
make lint-proxy      # Go only (from pkg/proxy, uses .golangci.yml)
make lint-ui         # Vue only (from pkg/ui)
```

Go format: `go fmt ./...` inside `pkg/proxy`. Vue format: `pnpm run lint` from `pkg/ui`.

## Mock generation

After any change to an interface in `pkg/proxy/internal/ports/`:

```bash
make mockery         # runs mockery + go mod tidy in pkg/proxy
```

Generated files land in `pkg/proxy/mocks/ports/` and are excluded from lint and test runs.

## Storybook

```bash
cd pkg/ui && pnpm run storybook         # dev on :6006
cd pkg/ui && pnpm run build-storybook   # static build
```

Every new component should ship with Default / Loading / Empty / Error stories.

## Conventions

- **Go**: hexagonal architecture — interfaces in `internal/ports/`, adapters in `internal/adapters/{aws,http}/`, application layer in `internal/application/`, manual DI in `bootstrap/wire.go`. Interface names end in `Port` or `er` (`S3Port`, `Reader`). Errors wrapped with `%w`. Table-driven tests.
- **Vue**: Composition API with `<script setup lang="ts">` + TypeScript (required). `defineProps<Props>()` + `defineEmits<{...}>()`. Props are never mutated directly — emit `update:modelValue`. Barrel exports (`index.ts`) per component folder. Pinia stores in `src/stores/`. Hash routing (`createWebHashHistory`).
- **Path alias**: `@/` → `pkg/ui/src`.
- **API client**: `pkg/ui/src/api/client.ts` wraps axios with mock SigV4 signing for local dev. Backend origin resolved per [Configuration § UI backend resolution](./configuration.md#ui-backend-resolution).

Full conventions, agent rules, and the per-role validation gates live in [`../AGENTS.md`](../AGENTS.md). Adding a new AWS service has its own 16–18 file checklist in [`../ADDING_SERVICES.md`](../ADDING_SERVICES.md).

## Release notes

Binary releases and Docker images are produced by the `v*` tag workflow in [`.github/workflows/`](../.github/workflows/). Assets:

- `mydevstack-proxy-<os>-<arch>` binaries attached to the GitHub Release.
- Docker image `beabys/mydevstack:<version>` and `beabys/mydevstack:latest` pushed to Docker Hub.

See [`upgrade.md`](./upgrade.md) for the upgrade and rollback procedures.

## PR checklist

- [ ] `make lint` clean.
- [ ] `make test` green (Go unit + integration).
- [ ] `pnpm run test:run` green from `pkg/ui`.
- [ ] New AWS service? Followed [`ADDING_SERVICES.md`](../ADDING_SERVICES.md) end-to-end (API client + composable + components + Storybook + view + route + sidebar + E2E).
- [ ] New component? Stories for Default / Loading / Empty / Error.
- [ ] Changed an interface in `internal/ports/`? Ran `make mockery`.
- [ ] Touch modal or async UI? `watch(..., { immediate: true })` + unit test mounts with `open: true`.
- [ ] No E2E written by anyone but QA — Dev owns unit + integration only.
- [ ] Docs updated if behavior / env var / port changed (`configuration.md`, `troubleshooting.md`).
- [ ] No `console.log`, `fmt.Println`, or ad-hoc logging left in.
